# 무드툰 (Moodtoon)

여러 플랫폼의 웹툰 정보를 한곳에서 찾아보고, 웹툰을 좋아하는 독자들과 소통할 수 있는 웹툰 커뮤니티입니다.

## 웹사이트

**[무드툰 웹사이트 바로가기](https://webtoonoooo.onrender.com/)**

[인기 웹툰 보기](https://webtoonoooo.onrender.com/#/explore?popular=true)

## 주요 기능

- 웹툰 검색, 장르·플랫폼 필터, 상세 정보 조회
- 좋아하는 웹툰 등록 및 인기 웹툰 조회
- 회원가입, 로그인, 마이페이지
- 게시판, 리뷰, 좋아요 및 댓글

## 기술 스택

| 구분 | 기술 |
| --- | --- |
| 프론트엔드 | React, Vite |
| 백엔드 | Java 21, Spring Boot |
| 데이터베이스 | PostgreSQL (Supabase) |
| 외부 데이터 | 한국만화영상진흥원 만화규장각 Open API |
| 배포 | Render |
